## Submit a form (sync)

```ts
submitForm(formName: string, formInput: Record<string, unknown>): void
```

Posts via analytics as category `'data-capture'`, method `'capturedata'`.

```js
import mobilelocker from '@mobilelocker/javascript-sdk'

mobilelocker.data.submitForm('lead-form', {
  firstName: 'Jane',
  email: 'jane@example.com',
})
```

## Products / labels / folders

```ts
getProducts(): Promise<Product[]>
getProduct(id: number): Promise<Product>
getLabels(): Promise<Label[]>
getLabel(id: number): Promise<Label>
getFolders(): Promise<Folder[]>
getFolder(id: number): Promise<Folder>
```

```js
const products = await mobilelocker.data.getProducts()
const product = await mobilelocker.data.getProduct(id)

const labels = await mobilelocker.data.getLabels()
const label = await mobilelocker.data.getLabel(id)

const folders = await mobilelocker.data.getFolders()
const folder = await mobilelocker.data.getFolder(id)
```

## Customers (platform list)

```ts
getCustomers(): Promise<Customer[]>
getCustomer(id: string): Promise<Customer>  // CRM object ID
```

```js
const customers = await mobilelocker.data.getCustomers()
const customer = await mobilelocker.data.getCustomer(crmObjectID)
```

For **session current/recent customers** and the native picker, use [`crm`](crm/) (`getCurrentCustomers`, `openCustomerPicker`, …).
