**Public surface (`user`):** `get`

```ts
get(): Promise<User>
```

## Get current user

```js
import mobilelocker from '@mobilelocker/javascript-sdk'

const user = await mobilelocker.user.get()
console.log(`Hello, ${user.name}`)
```

This is the usual **first success path** after the host injects `?jwt=` — see [Getting started](../guides/getting-started/). Failures throw **`MobileLockerError`**.
