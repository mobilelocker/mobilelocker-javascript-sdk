## Status

```js
import mobilelocker from '@mobilelocker/javascript-sdk'

const status = await mobilelocker.network.getStatus()
// status.connected — boolean
// status.type — 'wifi' | 'cellular' | 'wired' | 'none'

if (!status.connected) {
  // show offline UI; avoid CRM refresh / remote HTTP
}
```

Pair with [Errors](errors/) (`NotConnected`) when calls fail after a race with connectivity loss.
