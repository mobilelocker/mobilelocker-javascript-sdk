---
title: Share
description: Share presentations and send email from the host.
---

Share APIs are **synchronous** host bridges.

## Share a presentation

```js
import mobilelocker from '@mobilelocker/javascript-sdk'

mobilelocker.share.presentation(
  [{ email: 'jane@example.com', name: 'Jane' }],
  mobilelocker.notificationLevels.NOTIFY_FIRST,
)
```

### Notification levels

| Constant | Value | Meaning |
|----------|-------|---------|
| `NOTIFY_NONE` | 0 | No notifications |
| `NOTIFY_FIRST` | 1 | Notify on first open only |
| `NOTIFY_EVERY` | 2 | Notify on every open |
| `NOTIFY_WEEKLY` | 3 | Weekly digest |
| `NOTIFY_MONTHLY` | 4 | Monthly digest |

Available on the default export as `mobilelocker.notificationLevels`.

## Send email

```js
mobilelocker.share.email(
  { name: 'Jane', email: 'jane@example.com' },
  'Thanks for stopping by',
  'It was great to meet you.',
)
```
